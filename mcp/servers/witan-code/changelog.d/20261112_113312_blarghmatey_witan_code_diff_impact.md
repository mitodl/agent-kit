### Added

- `witan code diff-impact --base origin/main` maps a branch's diff to the symbols it changes, by parsing both sides of each changed file with the indexer's parser, then lists each symbol's callers, the bindings in other repos that share its env vars, endpoints and packages, the test files that name it (a stand-in for "tests to run", since the graph has no test-to-code edges), and the witan tasks and memories that cite it, plus the tasks claimed on the head branch. Every list carries its total next to what is shown (`--limit`, `--max-items`), changed test files are listed by file rather than looked up, and the notes say what the answer cannot see: an unindexed repo, symbols missing from the index, callers in other files, and callers only this branch adds. Tasks and memories are skipped, with a note, when witan (council) is not installed. Honors `--output-format`.
